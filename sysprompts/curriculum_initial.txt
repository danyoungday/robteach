This is the FIRST stage of the curriculum. There is no previous training — the policy starts from scratch.

Design the absolute simplest environment that is essentially guaranteed to produce early successes. The agent needs to experience positive rewards quickly to bootstrap learning.

Completely minimize the difficulty of the task so that the agent can easily succeed without completely destroying the task.

Consider strategies like:
- Placing the cube at the exact center of the table (zero spawn range) so the agent only needs to learn one reach trajectory
- Starting with the cube already in the gripper (scripted grasp) so the agent only needs to learn to lift
- Adding bonus rewards for partial progress

The environment should be simple enough that a randomly initialized policy easily stumbles into success within the first few thousand timesteps.
